## Scope and accuracy

This is a researched working catalogue, **not yet a fully verified exhaustive list of every available certification**. Several providers use dynamic or sign-in catalogues that could not be completely enumerated. Read each file's coverage notes before relying on it. [Coverage status](COVERAGE.md) identifies remaining work explicitly.

Entries include named certifications and, in labelled sections, related certificates, beta or announced awards, combined designations and exam pathways. The entry count is not a count of unique active certifications: shared credentials can appear in several tracks. Retired awards and legacy families are identified where relevant. Bundles, translated duplicates, training badges and microcredentials are generally excluded unless stated.

Official catalogue links are included in every vendor file. Availability, exam codes, prerequisites and renewals change; confirm with the provider before booking. Pearson VUE and PSI deliver exams and are not the issuing vendors.
