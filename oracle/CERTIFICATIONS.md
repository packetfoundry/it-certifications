## Coverage and verification

The public Oracle page mixes certification titles, exam subjects, upgrade and delta exams. This file preserves that distinction for database pathways. Delta versions are omitted as maintenance/upgrade routes rather than duplicate certifications. Coverage still needs the Financial Services and any catalogue sections beyond the retrieved inventory; not a claim that every historical/product exam is bookable.
